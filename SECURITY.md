# Security Policy

## Supported versions

Security fixes are applied to the latest released version.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Send a concise report to the maintainer using the email listed on the maintainer's GitHub profile. Include affected versions, reproduction steps, impact, and any suggested mitigation.

Do not include real credentials, tokens, or private data in reports or test cases. You can expect an initial response within seven days.
